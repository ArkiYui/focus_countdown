# 专注倒计时

一个简洁的网页专注倒计时工具，包含昼夜主题切换、随机花朵飘落动画以及今日专注时间统计。
选择下载，浏览器打开即可
focus_countdown_36themes_flowers.html-不含代办事项
focus_with_tasks.html-含代办事项

## 1. 专注倒计时

* 中央显示倒计时。
* 点击中央倒计时区域可以打开设置窗口。
* 可以设置 **1～10 小时**的专注时长。
* 支持：
  * 开始倒计时
  * 结束倒计时
  * 清除倒计时
* 页面底部显示当前时间。
* 页面会记录并显示**今日专注累计时间**。
* 
## 2. 36 种背景色调
总共包含 **36 种色调**。
### ☀️ 18 种明亮色调
适用于：
> **06:00 ～ 17:59**
主要使用：
* 浅蓝
* 浅绿
* 浅紫
* 浅粉
* 米黄
* 其他明亮柔和色系
### 🌙 18 种暗淡色调
适用于：
> **18:00 ～ 05:59**
主要使用：
* 深蓝
* 深绿
* 深紫
* 棕色
* 其他较暗色
* 
## 3. 每 2 分钟自动换色
背景色调会**每 2 分钟自动切换一次**。
* 白天只在 **18 种明亮色调**中循环。
* 夜间只在 **18 种暗淡色调**中循环。
* 到 **06:00** 自动切换到明亮色调。
* 到 **18:00** 自动切换到暗淡色调。
* 
## 4. 花朵动画
每朵花具有随机效果：
* 🌸 花瓣数量随机 **5～9 片**
* 🌸 花朵大小随机
* 🌸 飘落速度随机
* 🌸 移动方向随机
* 🌸 旋转角度随机
* 🌸 透明度随机
* 🌸 花朵持续生成
因此页面会持续出现不同大小、不同形态的花朵飘落。

### 花朵颜色
**白天：**
使用偏明亮、柔和的花朵颜色。
**夜间：**
使用偏暗淡、低透明度的花朵颜色。

## ⚠️ 注意
**这个版本不会保存你的学习/专注时间。**
所有数据都只保存在当前页面运行期间。
> **刷新页面后，今日专注时间会重置。**
关闭网页后重新打开，同样不会保留之前的学习时间。
目前版本**没有使用数据库、LocalStorage 或其他持久化方式保存学习时间**。
