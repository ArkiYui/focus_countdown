1. 专注倒计时
中央显示倒计时。
点击中央倒计时区域可以打开设置窗口。
可以设置 1～10 小时的专注时长。
支持开始、结束、清除倒计时。
页面底部显示当前时间。
页面会记录并显示今日专注累计时间。
2. 36 种背景色调

总共 36 种色调：

☀️ 18 种明亮色调
适用于 06:00～17:59
以浅蓝、浅绿、浅紫、浅粉、米黄等明亮色系为主。
🌙 18 种暗淡色调
适用于 18:00～05:59
对应较深的蓝、绿、紫、棕等色系。
3. 每 2 分钟自动换色
背景色调 每 2 分钟自动切换一次。
白天只在 18 种明亮色调中循环。
夜间只在 18 种暗淡色调中循环。
到 06:00 自动切换到明亮色调。
到 18:00 自动切换到暗淡色调。
4. 花朵动画
原来的羽毛已经完全去掉，改成了飘落的花朵。
每朵花：
花瓣数量随机 5～9片。
花朵大小随机。
飘落速度、移动方向随机。
旋转角度随机。
透明度随机。
花朵数量持续生成，因此页面会一直有花朵飘落。
白天使用偏明亮、柔和的花朵颜色。
夜间使用偏暗淡、低透明度的花朵颜色。
